# AgentForge

An experimental platform for studying autonomous AI agents through reproducible simulations.

## First laboratory: Dungeon Evolution Lab

The Dungeon Evolution Lab explores agent planning, memory, adaptive strategies, multi-agent systems, and procedural challenge generation. It begins as a controlled dungeon simulation and is designed to transfer findings to real-world agentic systems.

**Current status:** initial architecture and experimental design documentation; application code is not implemented yet.
